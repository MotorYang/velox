Native macOS Terminal

一个窗口完成终端、SSH 与 SFTP 工作流

Velox 使用 SwiftUI、AppKit、SwiftTerm、Citadel 和 SwiftNIO 构建， 把本地终端、远程 Shell、服务器资料、Keychain 凭据和文件传输整合进一个轻量的 macOS 原生工具。

Features

为高频远程开发任务准备

本地与远程终端

启动即进入本地终端；保存服务器后可快速打开 SSH Shell，并同步窗口标题和远程路径状态。

SFTP 文件面板

浏览远程目录、路径跳转、上传、下载、重命名和删除，不需要切换到独立文件传输工具。

拖拽上传

从 Finder 拖入文件或目录，Velox 会把它们上传到当前远程 SFTP 目录并显示传输状态。

服务器目录

按文件夹管理服务器资料，支持复制、编辑、删除和双击连接，适合维护多台主机。

Keychain 凭据

密码和私钥口令交给 macOS Keychain 存储，服务器资料只记录必要连接信息和私钥路径。

原生外观设置

支持终端字体、字号、窗口尺寸、亮色/暗色模式和透明度配置，贴合 macOS 桌面环境。

Workflow

少一次切换，多一点专注

Velox 的核心设计是把远程登录后的常见动作放在同一个上下文中： 连接服务器、查看目录、上传构建产物、下载日志、继续在 Shell 中操作。

  1. 01 保存服务器资料

    配置主机、端口、用户名和认证方式。

  2. 02 双击连接

    打开远程 Shell，同时准备 SFTP 会话。

  3. 03 传输文件

    通过文件面板或 Finder 拖拽完成上传下载。
