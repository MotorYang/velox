Features

Built for daily remote development tasks

Local and Remote Terminals

Start in a local terminal, then open SSH shells from saved server profiles with synchronized title and remote path state.

SFTP File Pane

Browse remote folders, jump to paths, upload, download, rename, and delete files without switching tools.

Drag-to-Upload

Drop files or folders from Finder into the remote pane and upload them to the active SFTP directory.

Server Directory

Organize servers in folders, clone profiles, edit connection settings, delete entries, and double-click to connect.

Keychain Credentials

Passwords and private-key passphrases are stored in macOS Keychain; profiles keep only required connection metadata.

Native Appearance

Configure terminal font, font size, window size, light or dark appearance, and transparency for a macOS-native workflow.

Workflow

Less context switching, more focus

Velox keeps common post-login tasks in the same context: connect to a server, inspect directories, upload build artifacts, download logs, and continue working in the shell.

  1. 01 Save server profiles

    Configure host, port, username, and authentication method.

  2. 02 Double-click to connect

    Open a remote shell and prepare an SFTP session at the same time.

  3. 03 Transfer files

    Upload and download through the file pane or Finder drag and drop.
